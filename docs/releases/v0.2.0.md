# MxPage v0.2.0

发布日期：2026-10-01

## 数量与完整工作流

- 头图最多 10 张、详情图最多 20 张，合计最多 30 张。
- 单商品和批量配置、API、旧版编辑器、导出、新版内容规划与视觉导演共用数量上限。
- 20 张详情图支持完整的 19 处衔接；新建默认 4 + 6，旧版手动规划保留单张模式。
- 引入基于 OpenAI Agents SDK 的内容规划、视觉导演、逐图复查和整套复查，保留检查点、方案草稿、图片版本与修正次数。

## 内容与视觉

- 将有依据的产品特征转换为买家价值，区分广告文案与 Agent 的观察、镜头和推理说明。
- 每张图分别规划内容任务、摄影、构图、主体占比、辅助模块和最终文案。
- 明确中文分行、字号、字重、行距、对齐及文字区坐标，按移动端阅读效果检查。
- 下一张详情参考原商品、上一张实际成图和底部色带，改进上下边缘的色彩衔接。
- 默认规划参数收尾，服饰覆盖上身和真实尺码信息；缺少的数据不虚构。
- 新增文件夹批量、多语言图片翻译、手机预览、分图 ZIP 和详情长图导出。

## 恢复与兼容

- 方案字段或衔接数据不完整时保存草稿和具体反馈，再次继续可修复同一方案。
- 规划请求遇到短暂断连或网关 5xx 时最多重试一次；鉴权和限流错误直接报告。
- 图像请求结果不确定时不自动重复提交；每张最多自动修正一次。
- 合并远端已有的编辑器新增参考图、任务取消、配置持久化、图片预览和 macOS 打包命令。

## 验证方法

运行 `npm test` 检查 SDK 工作流、30 张边界、19 处衔接、重试与恢复、文案和排版规则。测试使用本地模拟模型接口，不消耗生图额度，也不代表一次真实的 30 张付费视觉验收。运行 `npm run dist:win` 构建 Windows 安装包；安装包启动与迁移另作冒烟检查。

本次发布验证：168 项测试通过，TypeScript 检查和 Next.js 生产构建通过。`node scripts/smoke-desktop.cjs` 使用打包后的 Electron EXE 运行迁移和 HTTP 服务，验证空数据库初始化、项目创建、10 + 20 配置保存、配置页与参考图访问，并检查包内不含 `.env` 或数据库文件。此检查不涉及 Windows 安装向导的人工交互验收。
