## 榴莲 · 提示词排版预览

这张图来自排版改进时的单张设计验收：使用生产提示词编译器整理画面、最终文字与排版要求，再由图像模型生成预览。它不是应用网关自动完成的一整套商品页。

重点观察语义分行、标题与辅助文案比例、衬线字形、文字留白和商品摄影的关系。“云南产地”“重量300g”为该测试输入中的文字，不应推广为其他商品的事实。

![榴莲排版预览](durian-typography-preview.jpg)

图片中商品标识属于各自权利人，案例展示不代表品牌合作或背书。外部风格参考与这些生成案例分开存放，见 `public/ecommerce-references/`。
